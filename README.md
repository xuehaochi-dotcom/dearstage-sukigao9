# DEARSTAGE 好き顔9

DEARSTAGE公式ARTIST ALL（2026-09-21確認）を基準に、指定された11名を除外した61名版のプロトタイプです。

## 仕様
- 61人を毎回ランダムに18ブロックへ分配
- 4人ブロック×7、3人ブロック×11
- 各ブロック内は総当たり
- 各ブロック1位、計18人が決勝へ
- 決勝18人は完全総当たり（153試合）
- 勝利数でランキング
- 上位9人が「DEARSTAGE好き顔9」
- 同率時は直接対決、それでも決まらない場合は名前順

## 写真について
`images/` に以下の名前で画像を入れてください。
`a01.jpg` ～ `a61.jpg`

画像は公式サイト等から利用許諾を確認したうえで用意してください。

## GitHub Pages
1. GitHubで新しいPublicリポジトリを作成
2. このフォルダのファイルをアップロード
3. Settings → Pages → Deploy from a branch → main / root
4. 数分後に公開URLが発行されます。
